# Nova Enhance

Android app that enhances any text with AI — ChatGPT, Claude, Gemini, DeepSeek and Grok.

- **Capture:** Share menu, text-selection menu (with *Replace*), floating bubble, quick-settings tile.
- **Modes:** fix grammar, professional, shorten, expand, Arabic ⇄ English, architectural report tone, custom.
- **Engines:** your API keys, and/or your signed-in accounts inside the app.
- **History:** every conversation saved in the project **Enhancement**, one thread per AI, searchable, exportable.

Builds run on GitHub Actions; each build is published under Releases as `NovaEnhance-1.0-build-NN.apk`.
